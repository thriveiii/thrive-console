# Thrive Engineering Lessons

Hard-won lessons, one file per defect class, captured at the moment it is solved so the
next project does not relearn it the hard way. Format is fixed: Symptom, Root, How we
proved it, Fix, Guard. Written for reuse across Thrive projects (Console, Lotus, and
future work). These start in thrive-console; extract to a shared thrive-eng-library repo
once a second project needs them.
